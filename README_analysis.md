# Bedload transport analysis — data and code

Everything quoted in Section 5 of the manuscript and in Texts S5–S6, together
with Tables S1–S2 and Figure 2, is produced by one script from one data file.

## Files

| file | what it is |
|---|---|
| `data.csv` | the compilation, 239 points. Columns: `Gamma` (Shields stress Θ), `Q` (dimensionless transport rate Q\*), `Sources` (original study). Digitized from the published Q\*–Θ plot of Cheng (2020). |
| `fit_bedload.ipynb` | the whole analysis as a notebook, with the reasoning in markdown between the steps and all outputs stored. This is the readable version. |
| `fit_bedload.py` | the same analysis as a plain script, for running non-interactively. Both produce identical results. |
| `fit_results.json` | every number the script produces, written on each run. The manuscript quotes from this file. |
| `fig2.pdf`, `fig2.png` | Figure 2, regenerated by the script. |

## Running it

```
jupyter lab fit_bedload.ipynb     # or: python fit_bedload.py
```

Needs `numpy`, `scipy`, `pandas`, `matplotlib`. The notebook and the script are two views of the same code and write byte-identical `fit_results.json`. Takes about a minute, most of it
the 400-resample bootstrap. It writes `fit_results.json`, `fig2.pdf` and
`fig2.png` into the working directory and prints a summary of every fitted
value.

## What it computes, in order

1. **Near-threshold asymptote.** `ln Q* = ln A_f + (3/2) ln Θ − γ/Θ` fitted to
   all 239 points, with standard errors. This is the relation quoted in the
   main text.
2. **Stage-one capacity.** The Θ > 1 subset fitted with the exponent free (a
   test of the predicted 3/2) and then with the exponent held at 3/2 (which
   fixes the capacity coefficient `A`). Stage two conditions on this value.
3. **Full extreme-value closure.** Location, scale and shape fitted with the
   capacity held at the stage-one value, plus a bootstrap in which *both*
   stages are re-estimated inside each resample. Also runs two controls: the
   Gumbel limit with the amplitude free (which runs away, showing the
   degeneracy) and the Gumbel limit with the capacity fixed (which does not,
   showing that fixing the capacity is what removes it).
4. **Competing models.** Free power law, unsuppressed Θ^{3/2}, and
   Meyer–Peter–Müller. Each is fitted by the same criterion used to score it.
   MPM's threshold is chosen on a grid subject to covering every measurement,
   because the form is undefined below its own threshold and would otherwise be
   charged for points it cannot represent. A separate head-to-head refits every
   candidate on Θ > 0.06, where all of them apply.
5. **Diagnostics.** Residual bias and RMSE by Shields-stress band and by source.

## Notes for anyone re-running this

- Fits are performed on `ln Q*`, so residuals are multiplicative and all
  eleven decades of Q\* carry equal weight. RMSE values are therefore in
  natural-log units; `exp(RMSE)` converts them to a multiplicative factor.
- `THETA_C_LOC = 2/3` is the single-grain instantaneous threshold from the
  Bagnold force balance in the manuscript, not a fitted quantity. Everything
  said about σ₀ inherits its accuracy, which is order-of-magnitude only.
- `XI_SMOOTH` is computed, not assumed: it is the largest shape parameter on
  the search grid for which the lower endpoint of the fitted distribution stays
  clear of the data range. Figure 2 uses it so the plotted curve has no
  artificial corner; the unconstrained value is reported in Text S6.
- The bootstrap is seeded (`np.random.default_rng(0)`), so runs are
  reproducible.
